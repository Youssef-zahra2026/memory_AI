FAQ

Questions students ask

Is this just ChatGPT with a prompt?

No. It keeps a verified dependency graph of what you know, cites the theorems it used, and refuses to store an unverified claim. ChatGPT has no persistent model of your knowledge; it re-explains from scratch every time.

Does it work offline?

The first version runs a local 7B model on a laptop, so your data stays with you and answers cost almost nothing. A hosted version is coming for phones.

What math does it cover?

Linear algebra first: vector spaces, bases, dimension, linear maps, kernel and image, rank–nullity, eigenvalues, diagonalization, the spectral theorem. More courses are added based on student requests.

Can I trust the proofs?

Every answer is traceable to stored theorems and shows the dependency path. If a proof is wrong, you can see exactly which step or which stored result is responsible. Nothing enters the trusted memory without verification.

How much will it cost?

Free for the first 100 students. After the beta: 50 MAD/month in Morocco, $9/month internationally. If the price is a barrier, tell us — we'll work something out.
