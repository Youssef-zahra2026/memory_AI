## The one decision you have to make first

YC funds **companies**, not papers. The paper is evidence you can think; it is not the application.

You need to choose which company you are applying as. The recommendation in `01_strategy_memo.md` is:

> **An AI math tutor that remembers every mistake you make — built on a verified, self-compacting memory.**

Not "a memory layer for AI agents." That market is already owned by **Mem0** (YC S24, $24M raised, 200K+ developers, ~66K GitHub stars), with Zep, Letta, Cognee, Supermemory and others close behind. Your edge is not storage. It is **verified knowledge of one student** and a memory that gets smaller as it learns.

The long-term vision is still big: every high-stakes AI agent needs a memory it can prove is right. You start with math because a proof can be checked.

## The 10-step checklist

- [ ] Read `01_strategy_memo.md` and pick the story. Do not skip this.
- [ ] Buy a domain and deploy `landing/index.html` with a waitlist form.
- [ ] Record a raw 60-second demo on your phone. No editing. Watch it once. Re-record.
- [ ] Get **10 EMI classmates** to use the prototype this week. Watch them, do not help them.
- [ ] Fix the one thing that confused all 10.
- [ ] Draft every application answer in `03_application_draft.md`, then cut each answer by 30%.
- [ ] Record the 1-minute founder video: face + screen, under 60 seconds, no music.
- [ ] Run one mock interview with a friend who interrupts you every 15 seconds.
- [ ] Submit on **November 1**, not November 2.
- [ ] Keep the students using it while you wait. If you get an interview, the demo must still work.

## The honest sentence

You are early. You have a working prototype, a paper, and no users. That is enough to apply, not enough to assume you will get in. The application is worth doing because the 16-day sprint will force you to build the product, talk to users, and sharpen the story — and those things compound whether YC says yes or no.

Apply. Then keep building. Reapplying is normal.
